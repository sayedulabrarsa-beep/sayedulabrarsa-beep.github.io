Active Pharmaceutical Ingredient (API): From Raw Material to Medicine

Understand the active substance behind a medicine—and the quality steps between raw materials and a finished product.

Englishবাংলা

By Sayedul Abrar, pharmacist · Published 17 November 2026 · Updated 18 November 2026

The simple answer: An active pharmaceutical ingredient (API), also called a drug substance, is the substance in a medicine that provides the intended pharmacological activity or other direct effect. A tablet or capsule usually contains an API together with other ingredients that help form and deliver the medicine.

When you look at a tablet, you see the finished dosage form. But before that tablet is manufactured, its active ingredient must be produced or sourced, purified, tested and released under controlled quality systems. That active ingredient is the API.

1. What exactly is an API?

The International Council for Harmonisation (ICH) and the US Food and Drug Administration (FDA) describe an API as a substance or mixture of substances intended for use in manufacturing a drug product that becomes the active ingredient of that product. It is intended to provide pharmacological activity or another direct effect in diagnosis, cure, mitigation, treatment or prevention of disease, or to affect the structure or function of the body.

For example, in a conventional paracetamol tablet, paracetamol is the API. The tablet also contains excipients—ingredients that support manufacturing, stability, disintegration, appearance or other product characteristics. Excipients are not interchangeable with the API: they serve different functions.

2. API vs finished pharmaceutical product

An API is the active drug substance. A finished pharmaceutical product (FPP) is the medicine in its final dosage form, such as a tablet, capsule, oral liquid or injection, ready for the relevant packaging and supply steps.

  • API: the active substance that provides the intended pharmacological effect.
  • Excipients: other formulation ingredients used for functions such as binding, filling, coating, preservation or helping the dosage form perform as designed.
  • FPP: the formulated medicine containing the API and excipients in a defined dosage form and strength.

One company may manufacture the API and another may formulate it into tablets. Some organisations perform both activities. The business arrangement does not change the need to control the quality of the materials and processes.

  • API means active pharmaceutical ingredient; it is the active substance in a medicine.
  • The API is different from the finished tablet, capsule or liquid.
  • Manufacturing routes vary: chemical synthesis, extraction, fermentation and other processes may be used.
  • Purification, testing, documentation and GMP controls support API quality.
  • The quality of the API contributes to—but does not alone determine—the quality of the finished medicine.

Frequently asked questions

Is API the same as a drug?

In pharmaceutical manufacturing, API or drug substance refers to the active substance intended to provide the pharmacological effect. In everyday language, “drug” can have broader meanings.

Is an API the same as a tablet?

No. The API is the active substance. A tablet is a finished dosage form that usually contains the API plus excipients.

Can one company manufacture both API and tablets?

Yes. Some companies perform both API production and finished-product manufacturing, while others specialise in one activity or outsource part of the process.

Are all APIs made by chemical synthesis?

No. Depending on the substance, APIs may be produced through chemical synthesis, extraction, fermentation, cell culture or other suitable routes.

Why are API impurities tested?

Impurities can arise from starting materials, reactions, processing or storage. Testing and process controls help ensure that the API meets its defined quality requirements.

Does GMP guarantee that a medicine will never have a quality problem?

No system can guarantee that problems will never occur. GMP establishes controls for consistent production, detection, investigation and prevention of quality issues.

WHO's API GMP guidance defines manufacturing broadly to include receipt of materials, production, packaging and labelling, quality control, release, storage and distribution. GMP is therefore not just a final laboratory check; it is a connected system across the API supply chain.
