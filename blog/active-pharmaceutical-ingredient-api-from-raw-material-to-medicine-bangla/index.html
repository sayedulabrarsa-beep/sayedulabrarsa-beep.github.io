ফার্মা ব্লগ · ফার্মাসিউটিক্যাল ইন্ডাস্ট্রি · ৮ মিনিট

অ্যাকটিভ ফার্মাসিউটিক্যাল ইনগ্রেডিয়েন্ট (API): কাঁচামাল থেকে ওষুধ

একটি ওষুধের কার্যকর উপাদান কীভাবে তৈরি, বিশুদ্ধ, পরীক্ষা ও প্রস্তুত ওষুধে ব্যবহৃত হয়—সহজভাবে বুঝুন।

Englishবাংলা

লেখক: সাইয়্যেদুল আবরার, ফার্মাসিস্ট · প্রকাশিত ১৭ নভেম্বর ২০২৬

সহজ উত্তর: Active Pharmaceutical Ingredient (API) বা সক্রিয় ঔষধি উপাদান হলো ওষুধের সেই উপাদান, যা নির্ধারিত ফার্মাকোলজিক্যাল কার্যকারিতা বা সরাসরি প্রভাব তৈরি করে। একটি ট্যাবলেট বা ক্যাপসুলে API-এর পাশাপাশি আরও কিছু উপাদান থাকে, যেগুলো ওষুধের গঠন ও কার্যকারিতা বজায় রাখতে সাহায্য করে।

আপনি যখন একটি ট্যাবলেট দেখেন, তখন সেটি হলো প্রস্তুত ডোজেজ ফর্ম। কিন্তু সেই ট্যাবলেট তৈরির আগে এর সক্রিয় উপাদান তৈরি বা সংগ্রহ করতে হয়, বিশুদ্ধ করতে হয়, পরীক্ষা করতে হয় এবং নির্দিষ্ট মান পূরণ করলে তবেই ব্যবহার বা সরবরাহের জন্য ছাড়পত্র দেওয়া হয়। এই সক্রিয় উপাদানটিই হলো API।

১. API আসলে কী?

ICH এবং যুক্তরাষ্ট্রের FDA-এর সংজ্ঞা অনুযায়ী, API হলো এমন কোনো পদার্থ বা পদার্থের মিশ্রণ, যা ওষুধ তৈরিতে ব্যবহারের জন্য নির্ধারিত এবং প্রস্তুত ওষুধে সক্রিয় উপাদান হিসেবে কাজ করে। এটি রোগ নির্ণয়, নিরাময়, উপশম, চিকিৎসা বা প্রতিরোধে ফার্মাকোলজিক্যাল কার্যকারিতা বা অন্য কোনো সরাসরি প্রভাব দিতে পারে।

উদাহরণ হিসেবে, একটি সাধারণ প্যারাসিটামল ট্যাবলেটে প্যারাসিটামল হলো API। ট্যাবলেটে এর পাশাপাশি excipients বা সহায়ক উপাদানও থাকতে পারে। এসব উপাদান ট্যাবলেট তৈরি, স্থায়িত্ব, ভাঙন, আবরণ বা অন্যান্য বৈশিষ্ট্য বজায় রাখতে সাহায্য করে। API এবং excipients-এর কাজ এক নয়।

২. API ও প্রস্তুত ওষুধের পার্থক্য

API হলো সক্রিয় ঔষধি উপাদান। আর Finished Pharmaceutical Product (FPP) হলো নির্দিষ্ট মাত্রা ও ডোজেজ ফর্মে প্রস্তুত ওষুধ—যেমন ট্যাবলেট, ক্যাপসুল, সিরাপ বা ইনজেকশন।

  • API: ওষুধের সক্রিয় উপাদান, যা নির্ধারিত ঔষধি প্রভাব তৈরি করে।
  • Excipients: বাইন্ডার, ফিলার, কোটিং বা সংরক্ষণে সহায়তাকারী উপাদানসহ অন্যান্য ফর্মুলেশন উপাদান।
  • FPP: API ও সহায়ক উপাদান দিয়ে তৈরি নির্দিষ্ট ডোজেজ ফর্মের প্রস্তুত ওষুধ।

একটি প্রতিষ্ঠান API তৈরি করতে পারে, আর অন্য প্রতিষ্ঠান সেই API ব্যবহার করে ট্যাবলেট বা ক্যাপসুল তৈরি করতে পারে। আবার কোনো প্রতিষ্ঠান দুই ধরনের কাজই করতে পারে। তবে যে প্রতিষ্ঠানই কাজ করুক, উপাদান ও উৎপাদন প্রক্রিয়ার মান নিয়ন্ত্রণ জরুরি।

৩. API কীভাবে তৈরি হয়?

সব API একই পদ্ধতিতে তৈরি হয় না। ICH Q7-এ API উৎপাদনের কয়েকটি পদ্ধতির কথা বলা হয়েছে—যেমন chemical synthesis, extraction, fermentation বা cell culture এবং প্রাকৃতিক উৎস থেকে উপাদান সংগ্রহ। কোন পদ্ধতি ব্যবহার হবে, তা নির্ভর করে API-এর প্রকৃতি ও উৎপাদন প্রক্রিয়ার ওপর।

API তৈরির সহজ ধাপ

এটি একটি ধারণামূলক চিত্র। প্রকৃত উৎপাদন ধাপ, নিয়ন্ত্রণ ও গ্রহণযোগ্যতার মান API এবং অনুমোদিত প্রক্রিয়া অনুযায়ী ভিন্ন হতে পারে।

ধাপ ১: Starting materials বা প্রাথমিক উপাদান

উৎপাদন শুরু হয় নির্ধারিত starting materials, reagents, solvents অথবা জৈবিক উপাদান দিয়ে। এগুলোর পরিচয়, গুণগত মান ও ব্যবহারের উপযোগিতা যাচাই করা জরুরি। সরবরাহকারী যাচাই, নির্দিষ্ট মানদণ্ড, নমুনা পরীক্ষা এবং traceability-এর মাধ্যমে অনুপযুক্ত উপাদান উৎপাদনে প্রবেশের ঝুঁকি কমানো হয়।

ধাপ ২: উৎপাদন ও প্রক্রিয়া নিয়ন্ত্রণ

Chemical synthesis-এর ক্ষেত্রে নিয়ন্ত্রিত রাসায়নিক বিক্রিয়ার মাধ্যমে starting materials থেকে এক বা একাধিক intermediate তৈরি হয়ে কাঙ্ক্ষিত API পাওয়া যায়। অন্য API extraction, fermentation বা cell-based process-এর মাধ্যমেও তৈরি হতে পারে। উৎপাদন পদ্ধতি অনুযায়ী তাপমাত্রা, সময়, pH, mixing বা অন্যান্য গুরুত্বপূর্ণ বিষয় পর্যবেক্ষণ করা হয়।

ধাপ ৩: পৃথকীকরণ ও বিশুদ্ধকরণ

উৎপাদিত মিশ্রণ থেকে কাঙ্ক্ষিত উপাদান আলাদা করা হয় এবং অনাকাঙ্ক্ষিত পদার্থ দূর করা হয়। প্রক্রিয়া অনুযায়ী filtration, crystallisation, washing, drying বা অন্যান্য purification পদ্ধতি ব্যবহার হতে পারে। লক্ষ্য হলো নির্ধারিত মান পূরণ করে এমন API পাওয়া।

ধাপ ৪: Physical processing ও packaging

কিছু API-এর ক্ষেত্রে milling, micronisation বা blending-এর মতো physical processing করা হয়, যাতে নির্দিষ্ট বৈশিষ্ট্য অর্জন করা যায়। এরপর উপযুক্ত পাত্রে API প্যাক করা হয় এবং পরিচয়, সংরক্ষণ ও পরিবহনের জন্য প্রয়োজনীয় নিয়ন্ত্রণ রাখা হয়।

৪. API-এর মান কীভাবে পরীক্ষা করা হয়?

API নির্ধারিত specification পূরণ করছে কি না, তা পরীক্ষা করে দেখা হয়। API ও তার ব্যবহারের ধরন অনুযায়ী পরীক্ষার ধরন ভিন্ন হতে পারে। সাধারণত নিচের বিষয়গুলো পরীক্ষা করা হতে পারে:

  • Identity: পদার্থটি সঠিক API কি না তা নিশ্চিত করা।
  • Assay বা content: API-এর পরিমাণ বা শক্তি নির্ধারণ করা।
  • Related substances ও impurities: উৎপাদন বা সংরক্ষণ থেকে আসা অমিশ্রণ পরীক্ষা করা।
  • Residual solvents: উৎপাদনে ব্যবহৃত দ্রাবকের অবশিষ্টাংশ পরীক্ষা করা।
  • Water content ও physical properties: প্রয়োজন অনুযায়ী পানি ও অন্যান্য ভৌত বৈশিষ্ট্য যাচাই করা।
  • Microbiological quality: API-এর ধরন ও ব্যবহারের ভিত্তিতে প্রয়োজনীয় জীবাণু-সংক্রান্ত পরীক্ষা করা।

একটি পরীক্ষায় উত্তীর্ণ হলেই API-এর সব মান নিশ্চিত হয় না। সম্পূর্ণ specification, প্রাসঙ্গিক পদ্ধতি এবং batch documentation একসঙ্গে পর্যালোচনা করতে হয়। নির্ধারিত Quality Unit ফলাফল ও নথি যাচাই করে API ব্যবহার বা সরবরাহের জন্য release অথবা reject করার সিদ্ধান্ত দেয়।

৫. API উৎপাদনে GMP কেন গুরুত্বপূর্ণ?

Good Manufacturing Practice (GMP) হলো এমন একটি নিয়ন্ত্রণব্যবস্থা, যা নিশ্চিত করতে সাহায্য করে যে উৎপাদন ও মান নিয়ন্ত্রণ নির্ধারিত গুণগত মান অনুযায়ী ধারাবাহিকভাবে হচ্ছে। ICH Q7 বিশেষভাবে API উৎপাদনের জন্য GMP নির্দেশনা দেয়।

বাস্তবে GMP-এর মধ্যে রয়েছে প্রশিক্ষিত কর্মী, উপযুক্ত স্থাপনা ও যন্ত্রপাতি, লিখিত পদ্ধতি, নিয়ন্ত্রিত উৎপাদন রেকর্ড, পরিষ্কার-পরিচ্ছন্নতা ও রক্ষণাবেক্ষণ, deviation investigation, change control, laboratory control, supplier oversight এবং Quality Unit-এর দায়িত্ব।

GMP-এর অর্থ এই নয় যে কখনো ভুল হবে না। বরং এর উদ্দেশ্য হলো সমস্যা প্রতিরোধের ব্যবস্থা রাখা, সমস্যা শনাক্ত করা, তদন্ত করা, সিদ্ধান্ত নথিভুক্ত করা এবং পণ্যের মান সুরক্ষিত রাখা।

৬. রোগীর জন্য API-এর মান কেন গুরুত্বপূর্ণ?

API-এর গুণগত মান প্রস্তুত ওষুধের মানের একটি গুরুত্বপূর্ণ অংশ। API-এর পরিচয়, শক্তি, impurity profile বা অন্য গুরুত্বপূর্ণ বৈশিষ্ট্য নিয়ন্ত্রণে না থাকলে প্রস্তুত ওষুধ নির্ধারিত specification পূরণ নাও করতে পারে। তাই শুধু গুঁড়ার চেহারা বা সরবরাহকারীর পরিচিতি দেখে API-এর মান নির্ধারণ করা যায় না।

তবে API-এর মানই পুরো ওষুধের মান নির্ধারণ করে না। Finished-product manufacturer-কে formulation, উৎপাদন, packaging ও stability-ও নিয়ন্ত্রণ করতে হয়। API quality হলো বৃহত্তর pharmaceutical quality system-এর একটি অংশ।

৭. বাংলাদেশে API উৎপাদনের প্রসঙ্গ

বাংলাদেশে প্রস্তুত ওষুধ উৎপাদনের একটি প্রতিষ্ঠিত শিল্প রয়েছে। পাশাপাশি দেশে API উৎপাদন সক্ষমতা বাড়ানোর উদ্যোগ ও বিনিয়োগের বিষয়ও আলোচিত হয়েছে। এ বিষয়ে বাংলাদেশ বিনিয়োগ উন্নয়ন কর্তৃপক্ষ (BIDA) এবং ঔষধ প্রশাসন অধিদপ্তরের (DGDA) সরকারি তথ্য দেখা যেতে পারে। তবে বাংলাদেশে ব্যবহৃত প্রতিটি ওষুধের API দেশেই উৎপাদিত হয়—এমন ধারণা করা ঠিক নয়। উপাদানের উৎস ও সরবরাহব্যবস্থা ওষুধ এবং প্রস্তুতকারকভেদে ভিন্ন হতে পারে।

DGDA বাংলাদেশের জাতীয় ঔষধ নিয়ন্ত্রক কর্তৃপক্ষ। বর্তমান নিয়ন্ত্রক শর্ত জানতে সাধারণ ব্যাখ্যার ওপর নির্ভর না করে DGDA-এর প্রকাশনা ও প্রযোজ্য আইন দেখা উচিত।

মূল কথা

  • API অর্থ Active Pharmaceutical Ingredient—ওষুধের সক্রিয় উপাদান।
  • API এবং প্রস্তুত ট্যাবলেট, ক্যাপসুল বা সিরাপ এক জিনিস নয়।
  • Chemical synthesis, extraction, fermentation-সহ বিভিন্ন পদ্ধতিতে API তৈরি হতে পারে।
  • Purification, testing, documentation এবং GMP API-এর মান নিয়ন্ত্রণে সাহায্য করে।
  • API-এর মান প্রস্তুত ওষুধের মানে গুরুত্বপূর্ণ ভূমিকা রাখে, তবে এটিই একমাত্র নির্ধারক নয়।

সাধারণ প্রশ্নোত্তর

API কি ওষুধের জেনেরিক নাম?

সব ক্ষেত্রে একইভাবে বলা যায় না। API হলো সক্রিয় পদার্থ বা drug substance। জেনেরিক নাম সাধারণত সেই সক্রিয় উপাদানের স্বীকৃত নাম বোঝায়।

API কি ট্যাবলেটের সমান?

না। API হলো সক্রিয় উপাদান। ট্যাবলেট হলো API ও অন্যান্য উপাদান দিয়ে তৈরি একটি প্রস্তুত ডোজেজ ফর্ম।

একটি কোম্পানি কি API ও ট্যাবলেট দুটোই তৈরি করতে পারে?

হ্যাঁ। কিছু প্রতিষ্ঠান API উৎপাদন ও finished product manufacturing—দুটিই করে। আবার কিছু প্রতিষ্ঠান একটি নির্দিষ্ট কাজে বিশেষায়িত হয় বা অন্য প্রতিষ্ঠানের সঙ্গে চুক্তিতে কাজ করে।

সব API কি chemical synthesis দিয়ে তৈরি হয়?

না। API-এর ধরন অনুযায়ী chemical synthesis, extraction, fermentation, cell culture বা অন্য উপযুক্ত পদ্ধতি ব্যবহার হতে পারে।

API-এর impurity পরীক্ষা কেন করা হয়?

কাঁচামাল, রাসায়নিক বিক্রিয়া, উৎপাদন বা সংরক্ষণের সময় অমিশ্রণ তৈরি হতে পারে। পরীক্ষা ও প্রক্রিয়া নিয়ন্ত্রণের মাধ্যমে API নির্ধারিত মান পূরণ করছে কি না তা যাচাই করা হয়।

GMP থাকলে কি কখনো ওষুধের মানের সমস্যা হবে না?

কোনো ব্যবস্থাই সব ধরনের সমস্যা কখনোই হবে না—এমন নিশ্চয়তা দেয় না। GMP ধারাবাহিক উৎপাদন, সমস্যা শনাক্তকরণ, তদন্ত ও প্রতিরোধের জন্য নিয়ন্ত্রণব্যবস্থা তৈরি করে।

বাংলাদেশের বৃহত্তর প্রেক্ষাপট বুঝতে বাংলাদেশের ওষুধশিল্প কী? পড়ুন—এখানে API কীভাবে ওষুধ উৎপাদন ও সরবরাহ ব্যবস্থার সঙ্গে যুক্ত তা জানা যাবে।
