Generic Name vs Brand Name: What’s the Difference?

Why can two medicine boxes have different brand names but list the same active ingredient? This guide uses clear examples, a quick comparison, and a practical label check to explain the difference between a generic name, a brand name, and a formulation.

In this articleGeneric nameBrand nameQuick comparisonLabel checkFAQs

Quick answer: A generic name identifies the active ingredient in a medicine. A brand name is the name a manufacturer uses to market a particular product. The same active ingredient may be sold under different brand names, so the two names answer different questions: “What ingredient is it?” and “What is this product called?”

Think of it this way: the generic name is like a person’s common name; the brand name is like the name used by a particular company for its product. It is a memory aid—not a rule for choosing or switching medicines.

1. What is a generic name?

The generic name is the recognised name of the active ingredient—the substance responsible for the medicine’s intended pharmacological effect. For example, paracetamol is a generic name used for pain and fever relief.

2. What is a brand name?

A brand name is a product name selected by a company. For example, Panadol is a brand name associated with paracetamol products in many markets. Product formulations, strengths and availability can differ, so always read the label rather than relying on the name alone.

Real-life pharma example

In Bangladesh, rabeprazole is the generic/active-ingredient name used in products such as Finix. Finix is a brand name. Finix MUPS also describes a particular formulation/technology presentation—MUPS is not the generic name. Always verify the exact active ingredient, strength and approved pack label before comparing products.

Remember the three layers: active ingredient, marketed product, and formulation. They are related, but they do not mean the same thing.

4. A real-life label check

Imagine two medicine boxes with different brand names. Before assuming they are the same, compare the active ingredient, strength (for example, 500 mg), dosage form (tablet, capsule or liquid), and directions. A shared generic name is an important clue, but it does not prove that every product is suitable for every person or situation.

5. An easy trick to remember

G = Ingredient; B = Business label. The generic name tells you what the active ingredient is; the brand name tells you what the product is called. This is a memory aid, not a substitute for checking the package.

Safety check: Different brands can contain the same active ingredient, but they are not automatically interchangeable in every situation. Check active ingredient, strength, dosage form and instructions. Ask a pharmacist or prescriber before changing a medicine.

6. Common questions

Can one generic name have many brand names?

Yes. The same active ingredient may be marketed under different brand names by different companies.

Are generic and brand names the same thing?

No. The generic name identifies the active ingredient; the brand name identifies a marketed product.

Is every product with the same generic name identical?

Not necessarily. Strength, dosage form, release characteristics and other ingredients may differ. Check the product label and follow professional advice.
